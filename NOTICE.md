# Notices and attribution

## OpenStreetMap

The road network in `public/data/graph.json` and the hospital locations in
`public/data/hospitals.json` are derived from OpenStreetMap.

> Map data &copy; OpenStreetMap contributors

OpenStreetMap data is available under the Open Database Licence (ODbL) 1.0. See
<https://www.openstreetmap.org/copyright>.

Because these files are a derived database, they remain subject to the ODbL
regardless of the licence covering the source code in this repository. Attribution is
shown on the map itself, on the landing page, on the About page and here.

## What this project is not connected to

Pulse is a simulation. It is not connected to BMC, the 108 ambulance service, or any
hospital system, and it does not consume any live data feed. Bed counts, ambulances,
casualties and supplies are simulated. See the About page for the full scope
statement.
